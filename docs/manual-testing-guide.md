### 第 5 步：开球（关键测试）

**操作**:
1. 等待 "KICKOFF" 提示
2. 按 **K** 键（短传）进行开球

**检查项**:
- [ ] 球员响应按键

**预期**: ✅ 开球正常，传球距离看起来自然

### 第 6 步：基础操作

#### 6.1 移动 ✅
**操作**: 按 **W/A/S/D** 移动球员

**检查项**:
- [ ] 球员响应流畅
- [ ] 转向自然（不会瞬间转向）
- [ ] 速度合理

#### 6.2 短传 ✅
**操作**: 按 **K** 键短传

**检查项**:
- [ ] 球传向队友方向
- [ ] 传球距离合理（约 100-200 像素）
- [ ] 有传球吸附效果（自动微调方向）

**🔍 关键验证**: `ASSIST_MAGNET_RANGE_SHORT = 180px`，传球时如果队友在 180px 范围内，应该有明显的吸附效果。

#### 6.3 长传 ✅
**操作**: 按 **O** 键长传

**检查项**:
- [ ] 球有高弧度（能看到球的阴影）
- [ ] 传球距离更远（约 200-400 像素）
- [ ] 球落地后有反弹

#### 6.4 射门 ✅
**操作**: 
1. 带球接近对方球门（约 150 像素内）
2. 按 **J** 键射门

**检查项**:
- [ ] 射门动画播放
- [ ] 球快速飞向球门
- [ ] 有射门音效
- [ ] 球略微离地（初始高度 8px）

**🔍 关键验证**: AI 通常在 150px 距离内才会射门。手动射门在任何距离都可以。

### 第 7 步：AI 行为（观察模式）

**操作**: 
1. 停止操作（不按任何键）
2. 观察 AI 球员行为 30-60 秒

#### 7.1 进攻 AI ✅
**检查项**:
- [ ] AI 带球前进
- [ ] AI 会传球给队友
- [ ] AI 接近球门时会射门（约 150px 内）
- [ ] AI 跑位支援

**🔍 关键验证**: 
- `SHOT_DISTANCE = 150px` - AI 应该在这个距离开始射门
- 如果 AI 离得很远就射门，说明常量有问题

#### 7.2 防守 AI ✅
**检查项**:
- [ ] AI 追逐对方持球球员
- [ ] AI 接近时会铲球（约 15px）
- [ ] AI 会拦截传球路线

**🔍 关键验证**: 
- `TACKLE_DISTANCE = 15px` - 这是身体接触范围
- 铲球应该在非常近的距离触发（几乎贴身）

#### 7.3 门将 AI ✅
**检查项**:
- [ ] 门将站在球门线附近
- [ ] 球靠近时门将会出击（约 120-150px）
- [ ] 门将会扑救射门
- [ ] 门将抱球后会分配（大脚或手抛）

**🔍 关键验证**:
- `GOALIE_RUSH_OUT_DISTANCE = 120px` - 出击距离
- `GOALIE_CATCH_RADIUS = 20px` - 抱球范围（很小，需要精确）

### 第 8 步：球物理

#### 8.1 传球轨迹 ✅
**观察**: 传球时球的运动

**检查项**:
- [ ] 短传是地滚球（高度为 0）
- [ ] 长传有弧度（能看到球离地）
- [ ] 球有减速（摩擦力）
- [ ] 球滚动一段距离后停下

**🔍 关键验证**:
- `DISTANCE_HIGH_PASS = 90px` - 超过这个距离的传球会有弧度
- `GROUND_FRICTION = 60 px/s²` - 地面摩擦

#### 8.2 射门物理 ✅
**观察**: 射门时球的运动

**检查项**:
- [ ] 射门球速很快
- [ ] 射门有初始高度（略微离地）
- [ ] 射门球有下落（重力）
- [ ] 射门球摩擦力更大（停得更快）

**🔍 关键验证**:
- `SHOT_HEIGHT = 8px` - 初始高度
- `SHOT_GROUND_FRICTION = 120 px/s²` - 是普通球的 2 倍

#### 8.3 反弹 ✅
**观察**: 球撞墙或被挡后的反弹

**检查项**:
- [ ] 球撞墙会反弹
- [ ] 反弹有能量损失（不是完全弹性）
- [ ] 反弹方向合理

**🔍 关键验证**:
- `BOUNCINESS = 0.8` - 保留 80% 能量

## 🔍 重点观察项（常量验证）

以下是本次重构影响的关键距离，请特别注意：

### 距离感验证

**AI 射门距离** (~150px):
- 观察 AI 何时开始射门
- 目测距离应该是球场宽度的约 1/6
- 如果 AI 离得很远就射门 → 可能常量错误

**铲球距离** (~15px):
- 应该几乎贴身才能铲到
- 大约是球员身体宽度
- 如果隔着很远就能铲到 → 可能常量错误

**传球吸附** (~180px):
- 短传时会自动微调方向指向队友
- 吸附范围大约是球场宽度的 1/5
- 如果完全没有吸附 → 可能常量错误

**门将出击** (~120px):
- 球靠近球门时门将会主动出击
- 出击距离大约是禁区宽度
- 如果门将一直不出击 → 可能常量错误

### 与重构前对比

**如果你之前玩过这个游戏**:
- 所有手感应该**完全一样**
- 距离判断应该**完全一样**
- 如果发现任何差异 → 重构可能有问题

**如果是第一次玩**:
- 按照上述距离估算
- 游戏应该感觉"合理"和"自然"
- 不应该有明显的"太近"或"太远"的感觉

**Q: 游戏启动后看不到调试信息？**

**Q: 感觉距离不对劲？**
A: 记录具体情况（哪个距离，太远还是太近），这可能是 bug。

**Q: AI 行为很奇怪？**
A: 记录具体行为，可能是常量引用错误。

**Q: 游戏卡顿或崩溃？**
A: 立即停止，记录崩溃日志，可能是重构引入了错误。

**Q: 与重构前不一样？**
