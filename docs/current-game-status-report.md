## ⚠️ 已知问题

### 1. 场景中的硬编码值

**问题**: 场景文件（`.tscn`）中的碰撞体尺寸是硬编码的
**影响**: 改变球场尺寸时，碰撞体不会自动缩放
**解决方案**: 
- 方案 A: 手动调整场景
- 方案 B: 在 `_ready()` 中用代码动态设置

**优先级**: 中（仅在实际改变尺寸时才需要处理）

### 2. 部分支援跑位距离未缩放

**遗留常量**（在 `ai_behavior_field.gd`）:
```gdscript
const SUPPORT_RUN_WING_WIDTH := 70.0
const SUPPORT_RUN_FORWARD_PUSH := 90.0
const SUPPORT_MID_PUSH := 50.0
const SUPPORT_FULLBACK_PUSH := 60.0
```

**原因**: 这些是战术微调参数，暂时保留为绝对值
**影响**: 改变球场尺寸时，可能需要调整这些值
**优先级**: 低（可以在多尺寸测试时再决定）

### 3. 精灵尺寸固定

**问题**: 球员/球的精灵是固定尺寸的像素艺术
**影响**: 球场变大时，精灵可能显得太小
**解决方案**: 在代码中缩放精灵 `sprite.scale *= SCALE_FACTOR`
**优先级**: 中（取决于是否要支持大尺寸球场）
