# 射门系统手动测试检查清单

测试场景：主比赛场景（持球接近对方球门）
测试日期：________  测试人：________

## 基础流程

- [ ] 按住射门键，球员不会立即抬脚或停在僵直动作。
- [ ] 蓄力期间球仍由 `DRIBBLING` 控制，松开按键后才播放 `kick`。
- [ ] 蓄力满自动释放；球只在踢球动画结束触球一次。
- [ ] 射门音效与球速反馈正常。

## 方向与力量

- [ ] 不按方向时，球自动朝目标球门中心。
- [ ] 短按、长按射门的球速差异明显且不超过场地合理范围。
- [ ] 高 `shooting` 球员比低属性球员更少偏离目标。

## 取消与集成

- [ ] 蓄力未释放前按方向键，蓄力不中断且球员保持原带球方向。
- [ ] 蓄力期间方向键只影响释放时的球门上下轨迹微调。
- [ ] 射门后与门将扑救、折射、进球流程兼容。
- [ ] CPU 射门仍能进入动画并正常出球。

## 性能与结论

- [ ] 比赛保持稳定 60 FPS。
- [ ] 无红色运行时错误。
