# 射门系统变更记录

## 2026-08-31

- 新增可取消的射门蓄力流程。
- 蓄力期间保留带球，方向输入回到 MOVING。
- 新增 `ShootingPhysics` 自动瞄准和力量计算。
- 射门动画完成后才触球。

## 2026-09-01

- 修复奔跑/转身期间射门输入因转身锁和输入缓冲过期而无法进入蓄力的问题。
- 蓄力取消改为只响应蓄力开始后的新方向键，跑动中已按住的方向不会打断射门。
- 瞄准加入 technique、shooting、power 对目标线路和方向微调的影响；上下方向可微调球门上下区域。
- 调整蓄力期间方向输入：不再取消射门或改变球员带球方向，仅保留为出脚时的轨迹微调。
