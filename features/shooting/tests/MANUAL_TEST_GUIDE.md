# 射门系统独立手动测试

启动：

```bash
godot --path . features/shooting/tests/test_manual_scene.tscn
```

场景含两个可控球员、球、双方球门与实时状态面板。高属性球员默认持球并面向右侧目标球门。

| 操作 | 高射门属性 | 低射门属性 |
|---|---|---|
| 移动 | WASD | 方向键 |
| 射门蓄力 | J | 数字 7 |
| 切换持球测试球员 | 1 | 2 |
| 重置 | R | R |
| 瞄准线 | TAB | TAB |
| 退出 | ESC | ESC |

验证步骤：

1. 按住射门键，确认蓄力百分比上升，球员仍保持带球姿态。
2. 松开射门键，确认此时才播放踢球动作，动画结束后球射向右侧球门。
3. 重新蓄力但在松开前按移动方向，确认动作取消并继续带球，没有射门动画或出球。
4. 先按住移动方向再按射门，确认松开射门键仍会正常射门。
5. 蓄力开始后再改变方向，确认射门被取消且球员立刻继续带球。
6. 使用 `1` / `2` 对比射门属性 95/力量 180 与射门属性 35/力量 130 的速度反馈。
