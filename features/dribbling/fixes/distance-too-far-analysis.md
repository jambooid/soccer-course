# 带球距离问题深度分析

## 问题本质

用户反馈："一转身球就没了"

我的错误理解：需要在转向时修正球的方向
真正的问题：**球离身体太远了，转向时容易超出控制范围**

## 当前参数

```
TOUCH_ZONE_FRONT_OFFSET = 4.0 px
TOUCH_ZONE_LEN_MAX = 20.0 px（高技术）
MAX_CONTROL_DISTANCE_MAX = 100.0 px
```

理论触球区：球员前方 4px ~ 24px

## 实际运行情况

触球是**周期性**的，不是持续的！

### 带球循环
1. 球在触球区 (4-24px) → 触球 → 推出去
2. 球加速冲出触球区 → 在 24-100px 之间滚动
3. 球靠摩擦减速
4. 球滚回触球区 → 再次触球

**问题**：球的大部分时间在触球区**之外**！

### 估算球的平均距离

假设高技术球员（tech=98）满速带球：
- 触球将球推到约 40-50px 位置
- 球减速回落到 24px 才能再次触球
- **球的平均距离约 30-35px**

在 560×360 的低分辨率下，35px 已经很远了（约等于球员身高）。

## WE2000 的实现

WE2000 中球**紧贴**球员脚下：
- 视觉上球离球员约 5-10px
- 几乎感觉不到球和球员是分离的
- 转身时球立即跟随

## 根本解决方案

不是修正球的方向，而是**减小带球距离**！

### 方案 A：大幅减小触球区和推球力度

```gdscript
TOUCH_ZONE_FRONT_OFFSET = 2.0 px  // 从 4.0
TOUCH_ZONE_LEN_MAX = 12.0 px      // 从 20.0
TOUCH_ZONE_LEN_MIN = 6.0 px       // 从 10.0

// 同时减小推球倍率
PUSH_MULT_LOW_SPEED = 1.3         // 从 1.6
PUSH_MULT_HIGH_SPEED = 1.2        // 从 1.35
```

**效果**：
- 触球区：2-14px（紧贴脚下）
- 球推出距离更短
- 球的平均距离约 10-15px

### 方案 B：持续触球模式（激进）

完全改变机制：
- 触球冷却时间减小到几乎为 0
- 触球区扩大到覆盖整个合理范围
- 球几乎持续被推进，而不是周期性触球

**效果**：
- 球几乎一直在被"推"
- 更像是球被"粘"在脚上
- 更符合 WE2000 的手感

### 方案 C：混合模式（推荐）

1. 减小触球区和推球力（方案 A）
2. 增加触球频率（减小 MIN_TOUCH_INTERVAL）
3. 保留方向跟随修正（已实现）

```gdscript
TOUCH_ZONE_FRONT_OFFSET = 2.0 px
TOUCH_ZONE_LEN_MAX = 14.0 px
TOUCH_ZONE_LEN_MIN = 8.0 px
MIN_TOUCH_INTERVAL = 0.05         // 从 0.08
PUSH_MULT_LOW_SPEED = 1.4         // 从 1.6
PUSH_MULT_HIGH_SPEED = 1.25       // 从 1.35
```

## 测试目标

调整后，在测试场景中：
- 球应该紧贴球员脚下（目测 10-15px）
- 转身时球应该跟随，不会轻易丢失
- 仍保持物理感，不过度"磁吸"
