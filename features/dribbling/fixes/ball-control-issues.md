# 带球手感问题分析

## 用户反馈的三个问题

### 问题 1：带球时球离身体过远
**现象**：球和球员之间的距离看起来不自然，球太远了

**可能原因**：
- `TOUCH_ZONE_FRONT_OFFSET = 6.0` - 触球区前端偏移
- `TOUCH_ZONE_LEN_MAX = 28.0` - 触球区长度（高技术）
- 球的平均位置 ≈ 前方 32px（根据注释第 27 行）

**分析**：
32px 在 560×360 的低分辨率下确实显得较远。WE2000 的球通常贴得更紧。

### 问题 2：球在控制范围内但会丢失球权
**现象**：带球过程中，球明明在可控距离内，却突然失控

**可能原因**：
- `MAX_CONTROL_DISTANCE_MAX = 80.0px` - 最大可控距离
- 但触球区只有 28px 长
- 中间有 52px 的"死区"：球在这里不会触球，只靠摩擦减速
- 如果球冲出触球区太快，可能在到达 80px 前就失控

**分析**：
```
球员位置 → [6px 偏移] → [28px 触球区] → [46px 死区] → [80px 失控边界]
```
在死区内，球只减速不推进，容易误判为"还在控制中"但实际即将失控。

### 问题 3：球离球员很近但不获得球权
**现象**：球滚到球员脚边，但球员不自动控球

**根本原因**：
`BallStateFreeform.on_player_enter()` 只在球员**进入** `player_detection_area` 时触发，而不是持续检测。

**流程**：
1. 球进入 FREEFORM 状态
2. 球员已经站在球附近 → `body_entered` 不会触发（球员已经在里面了）
3. 球滚到球员脚边 → 没有新的 `body_entered` 事件
4. 球员不会自动控球

**解决方案需要**：
- 在 FREEFORM 的 `_process()` 中主动检测附近球员
- 判断球员是否在接球范围内，无对抗时自动给球权

## 修复计划

### 修复 1：缩小带球距离（P0）
- 减小 `TOUCH_ZONE_FRONT_OFFSET`：6.0 → 4.0
- 减小 `TOUCH_ZONE_LEN_MAX`：28.0 → 20.0
- 减小 `TOUCH_ZONE_LEN_MIN`：12.0 → 10.0
- 目标：球的平均位置从 32px → 20px 左右

### 修复 2：增大失控容差（P0）
- 增大 `MAX_CONTROL_DISTANCE_MAX`：80.0 → 100.0
- 目标：增加死区缓冲，减少意外失控

### 修复 3：主动接球检测（P0）
在 `BallStateFreeform._process()` 中：
- 扫描 `player_detection_area` 内的所有球员
- 找到最近的、可以控球的球员
- 判断距离 < 接球阈值（例如 15px）
- 判断无对抗（附近没有对方球员在更近的距离）
- 自动给予球权

## 预期效果

- 球更贴脚，看起来更自然
- 带球过程中不易误失控
- 球员靠近球时主动接球，手感流畅
