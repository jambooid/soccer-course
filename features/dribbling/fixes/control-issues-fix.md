# 控球体验问题修复

## 修复日期
2026-08-30

## 问题回顾

用户反馈的三个核心问题：

1. **球员切换过早** - 手动控制的球员在没有实质性得到球权时就切换
2. **移动响应迟钝** - 球员移动惯性过大，按键响应慢
3. **球不跟脚** - 获得球权后球容易脱离控制

## 修复内容

### 1. 球员切换逻辑修复（P0）

**问题根源：**
- `ActorsContainer._on_ball_possessed()` 监听 `ball_possessed_by` 信号
- 该信号在 `BallStateDribbling._enter_tree()` 时立即发出（第 36 行）
- 此时球员刚接球，还在 0.3 秒宽限期内，球权并不稳定

**修复方案：**
1. 新增信号：`GameEvents.ball_possession_stable(player)` - 宽限期结束后发出
2. 修改 `BallStateDribbling._process()` - 宽限期结束时发出稳定信号
3. 修改 `ActorsContainer` - 从监听 `ball_possessed_by` 改为 `ball_possession_stable`
4. 延长宽限期：从 0.3 秒增加到 0.5 秒

**修改的文件：**
- `scenes/screens/world/game_events.gd` - 添加 `ball_possession_stable` 信号
- `scenes/ball/ball_states/ball_state_dribbling.gd` - 宽限期结束时发出信号，延长到 0.5 秒
- `scenes/screens/world/actors_container.gd` - 切换监听目标信号

**效果：**
- 只有在球权稳定 0.5 秒后才会触发自动切换
- 避免接球过程中的频繁切换
- 玩家可以在宽限期内继续控制原球员，直到新球员真正控稳球

### 2. 移动响应速度提升（P0）

**问题根源：**
- `PlayerStateMoving.handle_human_movement()` 中减速系数只有 3.0
- 典型球员速度 60-80 px/s，减速度只有 180-240 px/s²
- 停下来需要 0.25-0.33 秒，手感迟钝
- 加速时直接设置 velocity，导致急转时惯性过大

**修复方案：**
1. 减速系数从 3.0 提高到 8.0（提升 2.67 倍）
2. 加速改为使用 `move_toward()` 插值，系数 10.0
3. 保持急转等其他机制不变

**修改的文件：**
- `scenes/characters/character_states/player_state_moving.gd`

**效果：**
- 停止响应时间从 ~0.3 秒缩短到 ~0.1 秒
- 方向切换更灵敏，符合"体验优先"原则
- 加速过程有轻微平滑，避免瞬间跳变但保持快速响应

### 3. 球跟脚稳定性提升（P1）

**问题根源：**
- 静止时吸附力只有 0.1，太弱
- 宽限期只有 0.3 秒，球权容易在刚接球时丢失

**修复方案：**
1. 静止吸附力从 0.1 提高到 0.3（提升 3 倍）
2. 宽限期从 0.3 秒延长到 0.5 秒（与切换逻辑共用）

**修改的文件：**
- `scenes/ball/ball_states/ball_state_dribbling.gd`

**效果：**
- 静止控球时球更紧贴脚下
- 接球后有更长的稳定时间
- 减少非对抗情况下的意外丢球

## 参数对比

| 参数 | 修复前 | 修复后 | 变化 |
|-----|--------|--------|------|
| 宽限期 | 0.3 秒 | 0.5 秒 | +67% |
| 减速系数 | 3.0 | 8.0 | +167% |
| 加速方式 | 直接设置 | move_toward(10.0) | 新增平滑 |
| 静止吸附力 | 0.1 | 0.3 | +200% |
| 切换触发 | ball_possessed_by | ball_possession_stable | 延迟 0.5s |

## 预期改进

### 定量指标
- 停止响应时间：0.3s → 0.1s（提升 67%）
- 切换延迟：~0.05s → 0.5s（更可控）
- 静止丢球率：预计降低 50%+

### 定性体验
- "即按即停" - 符合 WE2000 街机手感
- "稳定切换" - 不再在接球瞬间乱切
- "球随人走" - 静止/慢速时球更听话

## 后续优化空间

如果手感仍需微调，可以考虑：

1. **P2 优化**：动态吸附力 - 根据对手距离调整吸附强度
2. **P2 优化**：触球频率 - 减小触球冷却时间，让触球更密集
3. **P3 优化**：方向校正 - 球速度方向偏离球员方向太多时给予回正力

## 注意事项

- 所有修改都是参数调整或信号重定向，不涉及核心架构变更
- 兼容性：保留 `ball_possessed_by` 信号，只新增 `ball_possession_stable`
- AI 行为不受影响（CPU 球员不走自动切换逻辑）
- 性能无影响（只是改变信号触发时机）
